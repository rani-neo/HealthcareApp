# Healthcare App

This is a full-stack Healthcare App built using React, TypeScript, Node.js, Express, PostgreSQL, and Python.

## Features
- View patient list
- Delete patient
- Generate sample patient data with Python
- Bootstrap UI cards for patient display

## Tech Stack
- Frontend: React + TypeScript + Bootstrap
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL
- Data Generation: Python

## Run Backend
cd backend
npm install
npm run dev

## Run Frontend
cd frontend
npm install
npm start

## Run Python Data Generator
cd scripts
python data_generator.py
